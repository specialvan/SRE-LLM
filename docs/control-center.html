视觉方向

采用 maximalist mission-control editorial：黄铜高光、深海军蓝底、玻璃态硬面板、条带图与作战式密集信息分发，避免通用 SaaS 仪表盘气质。

前后端联通

前端通过 /api/control-center 直接读取 analysis/control_center_data.py 生成的控制栈 payload；服务入口为 python -m scripts.control_center_server。
