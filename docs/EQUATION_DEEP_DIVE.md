## §1 · Lossless Convexification

### 状态方程

```
ṙ = v                   (1.1)
v̇ = g + Γ / m           (1.2)
ż = −‖Γ‖ / (Isp · g0)    (1.3)
```

| 符号 | 含义 | 量纲 | 去掉会怎样 |
| --- | --- | --- | --- |
| `r` | 位置 | m | 没有它就没有"着陆点"概念 |
| `v` | 速度 | m/s | (1.1) 退化为 0=0 |
| `Γ` | 推力矢量 | N | 控制消失，火箭自由落体 |
| `m` | 瞬时质量 | kg | Isp 无从计算，燃料消耗无法建模 |
| `g` | 重力 | m/s² | 火箭会"浮"在当前高度 |
| `z = ln m` | 对数质量 | 无量纲 | 直接用 m 会让 (1.2) 的 `Γ/m` 非线性，破坏凸化 |
| `Isp · g0` | 有效排气速度 | m/s | 没有它，质量消耗模型不对 |

**为什么用 `z = ln m`**：质量 ODE `ṁ = −‖Γ‖/(Isp·g0)` 如果直接和 `v̇ = g + Γ/m` 放
在一起会出现 `Γ/m` 这个双变量乘积，非凸。取对数后 `ż = −‖Γ‖·e^{-z}/(Isp·g0)`，在
`z` 的一阶 Taylor 近似下变线性——这是 G-FOLD 的核心 trick 之一。

### 约束

```
‖Γ‖ ≤ σ                 (1.4  松弛)
ρ1 ≤ σ ≤ ρ2              (1.5  节流包络)
Γ · n̂ ≥ σ · cos θ_max     (1.6  指向锥)
```

| 符号 | 含义 | 去掉会怎样 |
| --- | --- | --- |
| `σ` | 松弛变量 | 没有它，`ρ1 ≤ ‖Γ‖` 是非凸约束 |
| `ρ1, ρ2` | 节流下/上限 | 发动机允许的推力范围 |
| `n̂` | 箭体当前对齐方向 | 没有它，推力矢量可以乱指 |
| `θ_max` | 最大指向偏差 | 防止气动/姿态失控的红线 |

**"无损"的含义**：Açıkmeşe & Ploen (2007) 证明，最小燃耗问题的最优解里 `σ` 一定等
于 `‖Γ‖`，所以引入的松弛没让问题变大。证明的核心在于 KKT 条件：目标函数不直接含
`σ`，只通过质量消耗 `ż` 间接影响，最优解里 `σ` 总是取到其上下界中能让 `‖Γ‖` 达标
的最小值。

### SRE 映射（连接池容量）

| 火箭 | SRE |
| --- | --- |
| `ρ1` 节流下限 | `min_keep_alive` 保活连接数 |
| `ρ2` 节流上限 | `max_capacity` 连接池硬上限 |
| `σ` 松弛 | scheduler 名义带宽 |
| `Γ` 实际推力 | 当前瞬时活跃连接数 |
| `Isp · g0` | 单连接·秒的 CPU 成本 |
| `θ_max` 指向锥 | 分流策略偏离名义比例的上限 |

对应代码：`sre_control/pool_planner.py :: PoolCapacityPlanner`。

## §2 · Successive Convex Programming

### 线性化

```
δẋ = A(t) · δx + B(t) · δu + c(t)    (2.1)

  A(t) = ∂f/∂x |_{(x̄, ū)}
  B(t) = ∂f/∂u |_{(x̄, ū)}
  c(t) = f(x̄, ū) − A·x̄ − B·ū          (残差，使 f_lin 在 (x̄, ū) 处等于 f)
```

| 符号 | 含义 | 去掉会怎样 |
| --- | --- | --- |
| `(x̄, ū)` | 当前参考轨迹/控制 | 没有参考点就没法线性化 |
| `δx, δu` | 相对参考的扰动 | 迭代的决策变量 |
| `A, B` | Jacobian | 线性模型的核心 |
| `c` | 常数项残差 | 没有 c 的话 `f_lin ≠ f` 在 (x̄, ū)，一阶点都不重合 |

### 置信域与更新

```
min  Σ (δx_kᵀ Q δx_k + δu_kᵀ R δu_k)      (2.2)
s.t. δx_{k+1} = A_k δx_k + B_k δu_k
     ‖δx_k‖∞ ≤ η_x                         (2.3)
     ‖δu_k‖∞ ≤ η_u
```

| 符号 | 含义 | 取值建议 |
| --- | --- | --- |
| `Q, R` | 代价权重 | Q 大 → 把轨迹压回参考；R 大 → 压低控制代价 |
| `η_x, η_u` | 置信域 | 初值给小一点（如 `‖x‖ · 0.1`），看改进比 ρ 动态调 |

**改进比自适应规则**（Levenberg-Marquardt 式）：

```
ρ = (J_true(x̄+δx) − J_true(x̄)) / (J_lin(x̄+δx) − J_lin(x̄))

if ρ > 0.7:   η ← η · 1.5       # 线性近似足够好，放大置信域
elif ρ < 0.1: η ← η · 0.5       # 近似很差，收缩
else:         η 不变
```

### SRE 映射（灰度置信域）

| 火箭 | SRE |
| --- | --- |
| `x̄` 当前参考 | 当前流量配比 |
| `A, B` Jacobian | SLO 对流量/副本的局部敏感度（历史斜率） |
| `η_x` 置信域 | 下一轮灰度允许的流量增量（默认 5%） |
| `ρ` 改进比 | 预期改进 / 实际改进（例：预期 P99 下降 5ms，实际下降 3ms → ρ=0.6） |

对应代码：`sre_control/canary_scheduler.py :: CanaryScheduler`。

## §3 · 6-DoF Rigid Body on SO(3)

### 运动学

```
q̇ = ½ · Ω(ω) · q                              (3.1)

         ┌  0   −ω_x  −ω_y  −ω_z ┐
  Ω(ω) = │  ω_x   0    ω_z  −ω_y │
         │  ω_y  −ω_z   0    ω_x │
         └  ω_z   ω_y  −ω_x   0  ┘
```

| 符号 | 含义 | 为什么是这个形式 |
| --- | --- | --- |
| `q = [w, x, y, z]` | 单位四元数 | 4 维参数化，避免欧拉奇异 |
| `ω` | 体坐标系角速度 | 3 维足够 |
| `Ω(ω)` | 4×4 反对称算子 | 让 `q̇·q⋆ = ½ω`（即 q 在单位球面上做"角速度 ω"的切向运动） |
| `½` | 因子 | 四元数覆盖 SO(3) 是 2:1 的，所以角速度要除 2 |

**验证方法**：令 `q(t) = exp(½ω·t)·q(0)`，代入 (3.1)，两边都是 `½Ω(ω)·q(t)`——这
也是为什么指数积分 `q_{k+1} = exp(½ω·dt) ⊗ q_k` 严格保单位范数。

### 动力学

```
ω̇ = J⁻¹ · (τ − ω × J ω)                       (3.2)
```

| 符号 | 含义 | 为什么 |
| --- | --- | --- |
| `J` | 惯量张量 | 3×3 对称正定 |
| `τ` | 体坐标系力矩 | 合成力矩 |
| `ω × Jω` | Euler 耦合项 | 不对称惯量下，不同轴角速度会"互相拖拽"；对称时（如球对称）消失 |

**工程经验**：Super Heavy 是细长圆柱，`J = diag(J_lat, J_lat, J_ax)`，
`J_lat ≫ J_ax`。当 ω_z（绕长轴自转）很大时 `ω × Jω ≈ (J_lat − J_ax)·ω_z·[ω_y; −ω_x; 0]`——
这就是为什么高速自转下 pitch/yaw 会有章动。

### SRE 映射（服务拓扑）

| 火箭 | SRE |
| --- | --- |
| `r ∈ ℝ³` | QPS/latency/CPU 等连续指标 |
| `q ∈ SO(3)` | 一致性哈希环位置、Raft term 方向、蓝绿切换角度 |
| `ω × Jω` 耦合 | 多维指标之间的非线性耦合（如 GC 停顿对 QPS 的反向影响） |

对应代码：`sre_control/topology_state.py :: TopologyState`。

## §4 · 推力指向锥

```
‖u‖ ≤ T_max                      (4.1)
n̂ᵀu ≥ ‖u‖ · cos θ_max            (4.2)
```

### (4.2) 的代数等价形式

设 `u = t·n̂ + x·ê_perp` 其中 `t = n̂ᵀu, x = u − t·n̂, ê_perp = x/‖x‖`。则：

```
‖u‖ = √(t² + ‖x‖²)
(4.2) ⟺  t ≥ √(t² + ‖x‖²) · cos θ_max
     ⟺  t² ≥ (t² + ‖x‖²) · cos²θ_max
     ⟺  t² · sin²θ_max ≥ ‖x‖² · cos²θ_max
     ⟺  t · sin θ_max ≥ ‖x‖ · cos θ_max  (假设 t ≥ 0)
     ⟺  t · tan θ_max ≥ ‖x‖                 ← 这是"冰淇淋锥"标准形
```

### 投影闭式解

给定 `(t₀, ‖x₀‖)`：

```
Case A (内部):    t₀ · tan θ ≥ ‖x₀‖                  →  u⋆ = u
Case B (极区):    t₀ · sin θ + ‖x₀‖ · cos θ ≤ 0       →  u⋆ = 0
Case C (侧投):    其它
    α = tan θ
    t⋆ = (t₀ + α·‖x₀‖) / (1 + α²)
    x⋆ = α · t⋆ · (x₀/‖x₀‖)
    u⋆ = t⋆·n̂ + x⋆
```

**然后**再把 `u⋆` 按比例缩到 `T_max`。两步投影顺序不能换——先缩到球会把一个本该落
在锥外的点拉到球内但仍在锥外。

### SRE 映射（SLO 护栏）

| 火箭 | SRE |
| --- | --- |
| `T_max` 推力上限 | 全集群 RPS 硬上限 |
| `n̂` 箭体轴 | 名义流量分布向量 |
| `θ_max` 锥半角 | 单步分布允许偏离名义的角度（如 15° ≈ 25% 相对偏差） |
| `u_nom` | NN/LLM-driven 建议的路由决策 |
| `u⋆` | 实际下发的 ConfigMap |

对应代码：`sre_control/slo_guardrail.py :: SLOGuardrail`。

## §5 · 扩展卡尔曼滤波

### 预测

```
x̂_{k|k−1} = f(x̂_{k−1|k−1}, u_k)                        (5.1)
P_{k|k−1} = F_k · P_{k−1|k−1} · F_kᵀ + Q_k                (5.2)
F_k = ∂f/∂x |_{x̂_{k−1|k−1}, u_k}
```

| 符号 | 含义 | 量纲 |
| --- | --- | --- |
| `x̂` | 状态均值估计 | 同状态 |
| `P` | 状态协方差 | (状态)² |
| `F` | 动态 Jacobian | 无量纲 |
| `Q` | 过程噪声协方差 | (状态)² / 步 |

**调 Q 的经验**：`Q_ii ≈ (model_error_std)² · dt`。如果 process 是真实物理过程（重
力），Q 可以很小（1e-3）；如果 process 是统计假设（OU 回归），Q 应该大一点。

### 更新

```
y_k = z_k − h(x̂_{k|k−1})                     (5.3  innovation)
S_k = H_k · P_{k|k−1} · H_kᵀ + R_k             (5.4  innovation cov)
K_k = P_{k|k−1} · H_kᵀ · S_k⁻¹                 (5.5  Kalman gain)
x̂_{k|k} = x̂_{k|k−1} + K_k · y_k               (5.6  state update)
P_{k|k} = (I − K_k · H_k) · P_{k|k−1}          (5.7  cov update)
```

**K 的直觉**：K 在 0（完全信任预测）和 1（完全信任观测）之间。

- `R_k` 大（观测噪声大）→ `S_k` 大 → `K` 小 → 不怎么修正
- `P_{k|k−1}` 大（预测不确定）→ K 大 → 大幅修正

**Joseph 形式**（数值更稳定）：`P_{k|k} = (I − KH) P_{k|k−1} (I − KH)ᵀ + KRKᵀ`。在
float32 的实时系统里强烈推荐。

### SRE 映射（信号融合）

| 火箭 | SRE |
| --- | --- |
| `x̂ = [r, v]` | `[qps, latency_ms, cpu_util]` |
| `f` 重力动力学 | OU 回归到目标值或从 AR 模型预测 |
| `h_radar` | Prometheus 1-min 聚合 |
| `h_imu` | 进程内每秒指标 |
| `h_vision` | RUM / 分布式追踪 |
| `Q` | 进程噪声 = 业务自然波动 |
| `R` | 观测噪声 = 监控系统采样误差 |

对应代码：`sre_control/signal_fusion.py :: SignalFusion`。

## §6 · MPC 滚动时域

### 代价函数

```
J = Σ_{k=0}^{N−1} (x_kᵀ Q x_k + u_kᵀ R u_k) + x_N^T P x_N     (6.1)
```

| 符号 | 含义 | 调参准则 |
| --- | --- | --- |
| `Q` | 阶段状态代价 | 按"想让状态收敛到 0"的程度加权 |
| `R` | 阶段控制代价 | R 大 → 控制更温柔，系统响应慢 |
| `P` | 终端代价 | 常取 `Riccati(Q, R)` 的解，让有限域 MPC 逼近 LQR |
| `N` | 时域长度 | 至少覆盖系统主导时间常数 |

### 约束

```
x_{k+1} = A_d x_k + B_d u_k    (6.2  离散动力学, ZOH)
u_min ≤ u_k ≤ u_max             (6.3  输入盒)
x_min ≤ x_k ≤ x_max             (6.4  状态盒, 可选)
x_0 = x̂_{now}                    (6.5  测量反馈)
```

### 滚动执行

```
solve → apply u_0 → shift warm-start:
    U_warm = [u_1, u_2, ..., u_{N−1}, u_{N−1}]
再 solve
```

**为什么 warm-start 降 30% 迭代**：解空间里最优解是连续的；相邻两拍的最优 `U` 差
一个 shift + 一个小扰动。从上一拍的解出发，活跃集（哪些约束绑定）基本不变，QP 求解
器只需要少量迭代。

### SRE 映射（预测式自动伸缩）

| 火箭 | SRE |
| --- | --- |
| `x = (r, v)` | `(replicas, rps_served)` |
| `u` | 下一拍的副本数调整 |
| `A_d, B_d` | 副本扩容延迟 / 容量线性模型 |
| `Q_11` | 状态偏差代价 = SLO 违反成本 |
| `Q_22` | 副本数偏差代价 = 实例费用 |
| `u_max` | 单步最大扩缩比例（滚动发布限制） |

对应代码：`sre_control/predictive_autoscaler.py :: PredictiveAutoscaler`。

## §7 · Bang-bang 最小时间

### Pontryagin 最小值原理给出的最优控制

对于问题 `min T  s.t. θ̈ = τ/J, |τ|≤τ_max, θ(0)=θ₀, θ(T)=θ_f, θ̇(0)=θ̇(T)=0`：

```
τ*(t) =  +τ_max   if  t < T/2
        −τ_max   if  t ≥ T/2
```

### 关键公式

```
T_min = 2 · √(|Δθ| · J / τ_max)             (7.1)
```

**推导**：前半段加速 `ω(T/2) = α·T/2 = τ_max·T/(2J)`；后半段刹停到 0，对称。位移
`Δθ = 2 × ½ α (T/2)² = α T²/4 = τ_max T²/(4J)`，解 T 即可。

### Switch point 监控

**注意**：bang-bang 对参数漂移极端敏感。实用做法是叠一个 PD 外环，只在 `|ω(t)·J/τ_max − (T − t)|` 超过阈值时触发回滚：

```
if |ω_measured · J / τ_max − (T − t)| > 0.1 · T:
    abort_switch()
```

### SRE 映射（快速切换）

| 火箭 | SRE |
| --- | --- |
| `Δθ = 90°` | 从 100% → 1% 流量的总位移 |
| `τ_max` | 每秒允许的流量变化上限 |
| `T_min` | 切换最少耗时 |
| Switch point | 健康检查确认点 |

对应代码：`sre_control/fast_switcher.py :: FastTrafficSwitcher`。

## §8 · 推力分配（有界最小二乘）

### 几何矩阵

```
A = ┌ d_1   d_2   ...  d_N ┐           (3×N, 方向)
    └ l_1×d_1  l_2×d_2  ...  l_N×d_N ┘   (3×N, 力矩臂)
```

对每台执行器 i：`d_i` 是推力单位方向，`l_i` 是相对质心的位置。第 i 列就是该执行
器单位推力贡献的 (力; 力矩) 6-D wrench。

### 分配问题

```
min_t ‖A · t − b‖²                (8.1)
s.t.  T_min ≤ t_i ≤ T_max           (8.2)
```

| 符号 | 含义 | 典型规模 |
| --- | --- | --- |
| `t ∈ ℝ^N` | 每台执行器的推力幅值 | N = 3 for Super Heavy |
| `b = [F; τ]` | 期望 6-D wrench | 6 |
| `A` | 几何矩阵 | 6×N |

**注意**：6×3 矩阵 A rank ≤ 3，所以不能精确重建任意 6-D wrench。最小二乘给出最
近似解；残差 `‖At − b‖` 反映"理论不可达"的那部分。

### 为什么用 lsq_linear 而不是 pinv

`pinv(A) · b` 是无约束最小二乘解，完全可能给出 `t_i < 0` 或 `t_i > T_max`。物
理执行器显然做不到（Raptor 不能负推力）。`lsq_linear` 在 Trust Region Reflective
框架下处理 box 约束，返回的 `t` 永远在 `[T_min, T_max]` 内。

### SRE 映射（加权负载均衡）

| 火箭 | SRE |
| --- | --- |
| `t_i` 每台推力 | 每实例 RPS 分配 |
| `F` 合力 | 全局 RPS 目标 |
| `τ` 力矩 | 区域约束（东/西机房、冷/热数据） |
| `l_i × d_i` 力矩臂 | 实例对某地理约束的贡献向量 |
| `[T_min, T_max]` | 实例 keep-alive 下限 / capacity 上限 |

对应代码：`sre_control/weighted_balancer.py :: WeightedLoadBalancer`。

## 复利：8 个支柱如何组合成 SRE 控制栈

```
        (signal)          (predict)        (trust)         (protect)        (execute)
           │                 │                │                 │                │
  §5 EKF Fusion ─→ §6 Predictive MPC ─→ §2 SCP Canary ─→ §4 Guardrail ─→ §8 Balancer
           │                                                                     │
           └──(observability)─────────────────────────────(actuation)────────────┘

静态配置：
    §1 Lossless PDG ─→ 连接池容量预算
    §3 Topology     ─→ 拓扑状态表示

应急路径：
    §7 Bang-bang    ─→ 紧急回滚 / 蓝绿切换
```

每个支柱都是 20-50 行代码的"单方程"。**复利**来自于：这些方程在结构上正交（§5 不关
心 §8 的内部、§8 不关心 §2 的内部），所以组合起来是**线性代码复杂度，非线性能力增
益**。

对应装配代码：`sre_control/stack.py :: SREControlStack`。
端到端示例：`examples/demo_sre_loop.py`。
基准对比：`analysis/s09_sre_stack.py`。
