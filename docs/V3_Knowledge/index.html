Z1Architecture & closed-loop data flow

7 层架构 + 一个 tick 内的完整数据路径。约束只向下传递（收紧），观测只向上汇报（只读）。

Key constraint: L6 envelope can only auto-tighten (ratchet). relax() is the sole widening path (L7 operator). L4 learner adjusts bias but cannot breach L2's floor/ceiling hard bounds. L3 observers are pure readers. See Z5 invariants.

Three closed loops in the system

Ingressprometheus/otel -> context -> combiner -> audit1 tick
Contractionplant gain -> JacobianMonitor -> ContractionWrapper -> effective_max_delta1 tick

Key architectural decisions (ADRs)

ADRDecisionContext
ADR-0001 ContractionAwareEnvelope uses RLock (not Lock) AI-3 required thread safety; RLock allows re-entrant calls from same thread (e.g. envelope.apply -> inner.check -> contraction monitor)

Design philosophy (accumulated across 10 rounds)

Safety-first: Every layer can only tighten constraints downward. Widening requires explicit operator action (relax()). This is the ratchet principle.
Audit-first: Every decision is recorded in AuditTrail before execution. Replay and credit assignment work on this immutable log.
Library, not service: No HTTP runtime, no DB, no message queue. Callers integrate these primitives into their own infrastructure. External dependencies are injected as callables.
Testable invariants: Every hard constraint has a regression test. If the test passes, the invariant holds. No "trust me" guarantees.

GLGlossary & references

Quick-reference terminology + external sources.

Core terms

AttnResAttention Residual: vertical inter-layer softmax-weighted residual
Sum a=1Softmax normalization: weights always sum to 1 (information conservation)
floor/ceilingPer-signal weight bounds (hard constraint from operator)
ratchetEnvelope can only auto-tighten, never auto-widen
relax()The sole API for operator-initiated envelope widening
quorumMinimum UNSAFE evidence quality to trigger tightening
hysteresisMargin retained during tightening to prevent boundary oscillation
OutcomeEvidence(safety_score, confidence) soft label tuple
contractionJacobian spectral radius < 1 ensures residual stability

Algorithm terms

FTRLFollow-The-Regularized-Leader (Hedge is neg-entropy special case)
HedgeMultiplicative weights update; O(sqrt(T ln n)) regret
creditTemporal credit assignment: post-incident signal blame
shadowShadow run: new controller parallel to baseline, no actuation
counterfactualMask one signal, recompute decision, measure delta
drift (KL/W1)KL catches collapse; Wasserstein catches translation
dead letterUnparseable audit line retained for debugging (FIFO capped)
ADRArchitecture Decision Record: required before breaking invariants
